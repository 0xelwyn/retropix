## ⚡ About RetroPix Pro

**RetroPix Pro** is a lightweight, zero-dependency, web-based procedural pixel art generator built with pure HTML5 Canvas and vanilla JavaScript. Designed specifically for indie game developers, retro art enthusiasts, and social media creators, RetroPix allows you to generate, edit, and export 8-bit avatars, monster sprites, and game assets instantly directly in your browser.

---

## ✨ Key Features

* <b>✦ Procedural Generation Engine:</b> Instantly create unique symmetric pixel patterns using customizable grid density and symmetry algorithms.
* <b>🔄 Symmetry Modes:</b> Supports Horizontal Mirror, Vertical Mirror, Quad-Symmetry, and Chaos (Randomized) modes.
* <b>🎨 Curated Color Palettes:</b> Built-in cyberpunk, synthwave, retro Game Boy, and PICO-8 color palettes.
* <b>🖌️ Manual Pixel Studio:</b> Complete drawing toolkit including Pencil, Eraser, and Flood Bucket Fill.
* <b>📱 Native Mobile & Android Support:</b> Optimized touch handlers for smooth drawing and editing on smartphones.
* <b>💾 One-Click Export:</b> Export high-resolution transparent PNG images directly to your device.
